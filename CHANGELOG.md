# Changelog

## 0.4.0 (unreleased)

- `idc ValueError:` runs a block and ignores that error
- `bruh()` opens the debugger, `@corememory` caches a function's results,
  `squad()` runs async tasks together
- Project words: add your own words in `[tool.slaython.words]` in
  `pyproject.toml`
- Helpers (`squad`, `pickone`, `bedrot`, ...) only count when called, so a
  variable with the same name keeps working
- `slaython build`, `slaython fmt`, `slaython lint` and a Jupyter kernel
- Docs site, live translator in the playground, pre-commit hooks, GitHub
  colours for .slay files, contributor guide and templates

## 0.3.0

- First release on PyPI
- `maincharacter:`, `lore` (dataclasses), `gang` (enums), `shoot n:`
  retries, `speedrun:`, `|>` pipes, `vibecheck` inline tests
- `howlongisit`, `headzortailz`, `pickone`
- `slaython glowup`, `slaython learn`, web playground, VS Code v2
- Error explanations start with "real talk:"

## 0.2.0

- Renamed: `orr`, `lockedin`, `nohead`, `shoot`, `fumble`, `ongod`;

  `skillissue`, `touchgrass`, `mee`), `runitfoo`, `deadass`,
  `yeet "message"`, `lowkeysus`, `bedrot`
- `slaython test`, `%%slay` for Jupyter, `slaython autoimport`, `--no-vibes`
