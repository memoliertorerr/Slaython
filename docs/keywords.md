# Keyword reference

Every word in Slaython, the Python it stands for, what the slang means, and
why it maps to that Python. Plain Python keywords work too, so you can use
either.

This page is generated from
[`slaython/keywords.py`](https://github.com/memoliertorerr/Slaython/blob/main/slaython/keywords.py)
each time the site is built. To change a word, change it there. The
[language guide](guide.md) shows each word in use, and `slaython keywords`
prints the same list in your terminal.

::: keyword-reference
